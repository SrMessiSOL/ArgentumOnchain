# Historical development records

This directory preserves earlier plans, UI reviews and validation reports. They record what was implemented or tested at a particular time; some include outdated URLs, build IDs or behavior.

Use the [current documentation index](../README.md) and [project README](../../README.md) for the current overview. Transaction and rehearsal evidence is grouped in [receipts](receipts/). Receipt files are historical test records, not live configuration or a complete production audit.

Screenshot references to private local artifacts may not resolve in a public clone. Those artifacts were not published during this reorganization.
