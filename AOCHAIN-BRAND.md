# AOCHAIN — Argentum Onchain

Brand direction: a serious fantasy MMORPG, with charcoal stone, antique gold, warm parchment, cinematic realm art and generous space. AOCHAIN is the short wordmark; Argentum Onchain is the full name. The website uses a custom vector crest, serif campaign headlines and clean sans-serif interface copy.

The homepage is now a complete public introduction with a realm illustration, entry and marketplace actions, gameplay/community/economy sections and an exchange showcase. Navigation, footer, account entry, character selection backdrop, metadata, app manifest and social previews share the identity. Original contributors and licenses remain credited.

Marketplace illustrations:

- Character cards render the actual listing’s body, head, weapon, shield and helmet through the existing game sprite renderer. A fallback icon is used if appearance data is unavailable.
- Item cards render the actual item’s sprite frame, using the server’s graphic identifier and the game’s graphics catalog. Missing assets fall back gracefully.
- The gold bridge uses an original AOCHAIN coin illustration. It is presentation artwork; it does not change the SPL mint or token metadata.

`frontend/public/brand/realm-hero-v1.png` is original AI-generated marketing key art, clearly labeled as a realm illustration on the landing page. It is not a gameplay screenshot. Next Image optimizes the landing image. Logo and coin artwork are native SVG assets. Original game sprites are preserved.

English is the default; Spanish copy remains available. Reduced-motion preferences, focus outlines, image fallbacks, mobile navigation and tablet spacing are supported. Payment signing, character transfer, escrow and gold settlement behavior are retained.
